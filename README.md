# MPC Platform

MPC Platform is the development repository for the Manufacturing Platform Core.

## Current Phase

Repository setup and foundation preparation.

## Repository Structure

- docs: Project documentation
- src: Source code
- tests: Test projects
- samples: Sample input/output files
- scripts: Build and automation scripts
- tools: Development tools
- .github: GitHub workflows and templates

## Development Method

Build from the smallest verifiable unit.

Each step must be:
- Defined
- Implemented
- Validated
- Frozen
